% Linear attention: the same product taken in two orders (Katharopoulos et al., 2020).
% Left: the n x n matrix A = phi(Q) phi(K)^T first, the only order open to
% softmax attention. Right: the r x d matrix M = phi(K)^T V first. Each product AB = C is
% drawn as in the matrix-product diagram: A to the left of C, B above it. n = 8, r = 3 and
% d = 3 are drawn; row i = 3 and column j = 6 are marked. The normalizer is left out of the
% drawing and stated in the bottom line. Operation counts are multiply-adds counted as two.
